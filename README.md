# Interactive Image Gallery

A small, browser-based image gallery built with plain HTML, CSS, and JavaScript. Add images by entering their URLs, then browse them in a responsive grid.

## Features

- Add images using a URL or by pressing Enter.
- Remove individual images from the gallery.
- Responsive layout with hover effects.
- Saves gallery state in browser storage. The current implementation may clear saved items when the page is reloaded.
- No frameworks, dependencies, or build step.

## Getting started

Clone or download the repository, then open [`index.html`](index.html) in a modern browser. No installation or server is required.

To add an image, paste a direct image URL into the input and select **Add Image**. For example:

```text
https://example.com/path/to/image.jpg
```

The image URL must be publicly accessible and usable by the browser. Select **Remove** on an image to delete it from the gallery.

The app's main files are [`index.html`](index.html), [`styles.css`](styles.css), and [`script.js`](script.js).
